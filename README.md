# Akarsh Trivedi Cricket Website

A ready-to-upload static GitHub Pages website for Akarsh Trivedi.

## Before publishing
Replace every placeholder beginning with `YOUR_` in `index.html`, `robots.txt`, and `sitemap.xml`.

Especially update:
- YOUR_GITHUB_PAGES_URL
- YOUR_CRICHEROES_URL
- YOUR_YOUTUBE_URL
- YOUR_INSTAGRAM_URL
- YOUR_BATTING_VIDEO_URL
- YOUR_WK_VIDEO_URL
- YOUR_EMAIL

Also replace the `AT` photo placeholder with a suitable cricket photo if desired.

## GitHub Pages
1. Create a public repository.
2. Upload `index.html`, `style.css`, `script.js`, `robots.txt`, and `sitemap.xml`.
3. Go to Settings → Pages.
4. Select the publishing source (for example, `main` branch / root).
5. Open the published site.

GitHub Pages uses `index.html` as an entry file for a static site.
